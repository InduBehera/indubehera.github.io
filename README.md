# Indu Behera Portfolio

GitHub Pages-ready static portfolio.

## Structure

- `index.html` — page content and metadata
- `assets/css/style.css` — all site styling
- `assets/js/script.js` — interactions
- `assets/images/` — extracted image assets

## Publish

Upload all files and folders to the root of the `indubehera.github.io` repository.

Google Analytics measurement ID `G-D0MKNL7XN9` is included in `index.html`.
